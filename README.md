# CloserFlow

A responsive sales and delivery command center that keeps opportunities, technical handoffs and review gates in one workspace.

## Highlights

- Drag-and-drop opportunity pipeline
- Create-opportunity workflow with live state
- Sales playbooks and delivery handoff views
- Responsive desktop and mobile layouts
- Zero dependencies: HTML, CSS and JavaScript only

## Run locally

```bash
python3 -m http.server 8000
```

Open `http://localhost:8000`. This is an original portfolio project using representative sample data.
